# FemCare AI

**An interactive women’s health dashboard for menstrual cycle tracking, symptom logging, and PCOS awareness.**

FemCare AI helps users explore menstrual health patterns and organize information for conversations with healthcare professionals. Built with React, the application brings together health logging, cycle forecasting, wellness guidance, and explainable risk awareness in one interface.

> FemCare AI is an educational prototype for awareness and decision support. It does not provide medical diagnoses or replace professional healthcare advice.

## Features

### Cycle and Symptom Tracking

Record menstrual cycle information and symptoms throughout the current session.

### Health Timeline

Review logged information in a chronological view to explore changes over time.

### PCOS Risk Awareness

Explore an illustrative risk estimate based on factors associated with PCOS.

### Explainable Insights

Understand how individual inputs contribute to the displayed estimate.

### Cycle Forecasting

Explore upcoming cycle estimates through a weighted forecasting approach.

### Nutrition and Mood Guidance

Access general wellness information related to nutrition and mood.

### Appointment Summary

Generate a printable summary to support conversations with a healthcare professional.

## How It Works

FemCare AI runs entirely in the browser without a backend or external API. Live risk estimates use deterministic feature contributions to provide fast, explainable results.

The model comparison shown in the interface is a demonstration. Live estimates are not generated by a deployed Random Forest model.

Logs are stored in React memory during the current session. Refreshing the page may clear this information.

## Demonstration Dataset

The application uses seeded synthetic data generated in the browser. Its reproducible dataset contains **420 synthetic records** covering:

1. Age and BMI
2. Cycle length and regularity
3. Hirsutism and acne
4. Weight gain and hair loss
5. Skin darkening
6. Fast food intake and exercise
7. Family history of PCOS
8. Left and right ovarian follicle counts

These records support educational exploration and do not represent real patients.

## Model Comparison

The interface presents a demonstration comparison between **Logistic Regression** and **Random Forest**, using an **80/20 training and evaluation split**.

Random Forest is displayed as the selected model with a **ROC AUC of 0.93** and an **F1 score of 0.86**.

These demonstration metrics do not establish clinical accuracy or performance on real patient data.

## Technology

The application uses **React** for its interface and session state. Synthetic data generation, live estimation, and cycle forecasting run in the browser. Appointment summaries use browser printing.

## Current Limitations

The application has not been clinically validated. Its synthetic dataset cannot establish performance across real patient populations.

Risk estimates cannot diagnose, confirm, or exclude PCOS. Cycle forecasts are approximate and may be less reliable for irregular cycles.

Session logs do not provide persistent storage.
